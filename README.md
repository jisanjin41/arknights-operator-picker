# Arknights Operator Picker · 明日方舟干员随机抽选

一个纯前端的明日方舟干员随机抽选小工具，打开 `index.html` 即可使用，无需安装或联网。

## 功能

- 收录 432 名可获得干员（一至六星），默认 10 人、只抽六星
- **抽取栏**：人数、常用人数和唯一的主按钮放在一起——没有结果时「抽取 N 位」，有结果时「重抽 N 位」（锁定的干员原位保留，N 为要重抽的人数）
- **再抽 +1 / +2 / +3 / +N**：保留现有结果再追加；不允许重复时避开已有干员，缺失的必出干员优先补进；还没抽时也能从零开始一个个加；卡池不足会提示
- **锁定**：点卡片或左上角锁按钮；结果上方可全部锁定、全部解锁、反选
- **单张操作**：卡片底部 ↻ 只重抽这一位，× 删除；锁定或必出的干员不能单张重抽；「删除全部」一次清空所有结果（包括锁定的）
- **撤销 / 重做**：抽取、重抽、再抽、添加、删除、锁定 / 解锁都能撤销（最多 30 步），撤销过头可以重做；快捷键 Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做（Mac 用 ⌘）
- **卡池设置**：星级、职业多选（Ctrl / Shift + 点击只选该项）；搜索中文名、全拼、首字母、混拼或英文名设为「必出 / 排除」，或用头像面板点选；允许重复开关
- **添加干员**：搜索结果里的「添加」按钮，或「＋ 添加干员」打开头像面板点选，把指定干员直接加入当前结果（不受筛选限制，可锁定、删除、撤销）；再点一次移出
- **复制名单**：中文顿号分隔；浏览器不允许直接复制时显示文本供手动复制
- **自动保存**：结果、锁定、筛选、人数、面板折叠和主题刷新后恢复
- **浅色 / 深色主题**：跟随系统或手动切换；直播画面不受影响
- **手机与键盘**：手机上结果两列，抽取栏固定在屏幕底部；Tab 可到达所有按钮，聚焦卡片按 Enter 锁定
- 每张卡片附精英化立绘，可跳转到 PRTS 查看详情

## 使用

- 在线：<https://arknights-operator-picker.pages.dev>（备用：<https://tonyshtark.github.io/arknights-operator-picker/>）
- 本地：下载后双击 `index.html`（`img` 文件夹需与其放在同一目录）

## 直播 / OBS 使用

### 推荐：OBS 浏览器源（不用把窗口放前台）

画面直接在 OBS 内显示，浏览器最小化或被游戏挡住也照常同步；背景透明，不需要绿幕。需要 OBS 28 或更新版本。

1. OBS 菜单「工具 → WebSocket 服务器设置」，勾选「开启 WebSocket 服务器」，点「显示连接信息」记下端口和密码。
2. 在主页面左侧展开「直播展示」，填写地址（默认 `ws://127.0.0.1:4455`）和密码，点「连接 OBS」。连接成功后会记住，下次打开页面自动重连。浏览器若询问是否允许访问本地网络设备，请选择允许。
3. OBS 添加「浏览器」来源，**不要勾选「本地文件」**，网址填面板里显示的那一行（以 `#obs` 结尾，可点「复制」），宽 1120、高 210（竖向可用 210 × 1120）。
4. 方向、形状、滚动速度在「直播展示」里调整，会实时同步。

原理：主页面通过 OBS 自带的 obs-websocket 调用 obs-browser 的 `emit_event`，把当前结果发给浏览器源；浏览器源会记住最后一次结果，刷新后立刻恢复。

### 备选：弹出小窗 + 窗口采集

Chrome / Edge 会暂停被遮挡或最小化的窗口，所以这种方式需要小窗一直可见（例如放在副屏）。

1. 在「直播展示 → 备选」里点「打开小窗」，抽取、重抽、再抽、添加、删除和撤销都会同步到小窗。
2. OBS 添加「窗口采集」来源，窗口选「小窗展示 · 干员抽选」；小窗顶部的地址栏可按住 Alt 拖动上边框裁掉，或用「裁剪/填充」滤镜裁掉。
3. 去掉背景（绿幕抠图）：小窗背景选「绿幕」，在 OBS 里右键来源 →「滤镜」→ 添加 **颜色键**（不建议用色度键，它会把同色系一起抠掉）：
   - 关键色类型：绿色
   - 相似度：200 左右（150～250）
   - 平滑：140 左右（100～200）
   - 头像边缘有绿边 → 调高平滑；绿色较多的干员（如嘉维尔、维荻）被抠出洞 → 调低相似度
   - 使用自定义背景色时，关键色类型选「自定义颜色」并填同一个色号
