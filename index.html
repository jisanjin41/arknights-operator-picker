背景
  • Chrome / Edge 会暂停被遮挡或最小化的窗口，小窗停止滚动、OBS 画面定格，所以这种方式需要小窗一直可见（例如放在副屏）。
  • OBS 来源选「窗口采集」，窗口选「小窗展示 · 干员抽选」；地址栏可按住 Alt 拖动上边框裁掉。
  • 绿幕抠图：背景选「绿幕」，滤镜添加颜色键（不要用色度键），相似度约 200、平滑约 140；边缘有绿边调高平滑，绿色多的干员被抠出洞就调低相似度。用自定义颜色时，关键色类型选「自定义颜色」并填同一色号。

使用说明

1抽取

  • 在上方抽取栏设置人数（− / ＋ 或常用人数 1 · 4 · 6 · 10 · 12），点抽取。
  • 抽完后同一个按钮变为重抽 N 位：锁定的干员原位保留，只重抽其余位置。
  • 再抽 +1 / +2 / +3 / +N：保留现有结果，再追加几位；不允许重复时不会抽到已有干员，缺失的必出干员优先补进。还没抽时也能直接用，从零开始一个个加。
  • 是否允许重复在左侧「卡池设置」最下方。

2锁定、单张重抽与删除

  • 点卡片或左上角锁按钮：锁定 / 解锁这位干员。
  • 结果上方可全部锁定、全部解锁、反选。
  • 卡片底部 ↻ 只重抽这一位（锁定和必出的不能单张重抽），× 删除这一位；删除全部一次清空所有结果（包括锁定的）。
  • 撤销 / 重做：抽取、重抽、再抽、添加、删除、锁定 / 解锁都能撤销，最多 30 步；撤销过头可以重做。快捷键 Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做（Mac 用 ⌘）。

3卡池

  • 星级、职业可多选；按住 Ctrl 或 Shift 点击只保留这一项。默认只抽六星。
  • 必出：每次抽取一定出现，不受星级、职业限制。排除：永远不会抽到。
  • 搜索支持中文名、全拼（chongyue）、首字母（cy）、英文名；或点「选择必出 / 选择排除」用头像面板点选。
  • 添加干员：搜索结果里的「添加」，或「＋ 添加干员」打开头像面板点选，把指定干员直接放进当前结果（不受筛选限制，可锁定、删除、撤销）；已在结果里的再点一次会移出。

4直播展示

  • 推荐 OBS 浏览器源：按左侧「直播展示」里的三步连接 OBS，画面在 OBS 内显示，浏览器可以最小化，背景透明。
  • 备选弹出小窗 + 窗口采集：需要小窗一直可见，被遮挡时浏览器会暂停它。
  • 方向、形状、滚动速度对两种方式都生效。

5其他

  • 复制名单：以顿号分隔的中文名。
  • 结果、锁定、筛选、人数、主题都会保存在本浏览器，刷新后恢复；撤销记录不保存。
  • 卡片右下角 PRTS 可跳转到干员详情页。Esc 关闭弹窗。
  • 收录 432 名可获得干员，不含预备干员与集成战略专用角色。
